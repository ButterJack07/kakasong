# 田园之间 · Little Lands

一个受卡卡颂启发的单人拼地图小游戏。纯前端，无需后端、数据库或账号；对局进度、音效设置和个人最高分保存在浏览器本地。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的地址。手机和电脑连接同一个 Wi-Fi，手机访问 `http://电脑局域网IP:5173` 即可试玩（需要允许开发服务通过本机防火墙）。这里的 Vite 是开发预览工具，游戏逻辑全部运行在浏览器里。

```sh
npm test          # 核心规则测试
npm run build    # 输出到 dist/
npm run preview  # 预览生产构建
```

浏览器回归检查：`npm run test:browser`，默认使用本机 Microsoft Edge，覆盖桌面、390px 和 320px 手机视口的放置、撤回、派遣、刷新恢复、回合结算、地图拖动及缩放。其他环境可先运行 `npx playwright install chromium`，再设置环境变量 `BROWSER_CHANNEL=chromium` 运行此检查。

推送到 `main` 后，GitHub Actions 会自动运行规则测试、构建并发布静态网页。仓库 **Settings → Pages → Build and deployment** 的来源选择 **GitHub Actions**。部署完成后，手机直接打开 `https://butterjack07.github.io/kakasong/` 即可玩，不需要应用服务器。项目入口也兼容 GitHub Pages 的直接静态文件托管；`dist/` 可以部署到 Cloudflare Pages、Netlify 等任意静态网站服务。

## 玩法

- 每局 36 块可用板块，候选区三选一，起始板块不占牌库。
- 点击候选、旋转，选择地图上的合法位置放置；相邻道路、城镇、草地必须匹配。
- 放置后可以派遣一个旅人，也可以直接结束回合。确认回合之前支持撤回。
- 共 5 位旅人，连通区域中已有旅人时不可再派遣。完工计分后旅人归来。
- 道路出口全部封闭，每块 1 分；城镇围合，每块 2 分；修道院周围 8 格填满，9 分。
- 三岔驿站的每一条路独立结算；双子城镇的两段城镇互不连通。
- 只有有旅人的区域计分；草地暂不提供农夫玩法。
- 每局可以换牌 3 次：当前板块回到牌库底部并补一块。牌库空后换为可放置的新板块。
- 最后一块放置后自动结算未完工建筑：道路每块 1 分、城镇每块 1 分、修道院按自身与邻居数计分。没有合法落点时也可提前结算。
- 达到 80 分，并完成至少 4 处有旅人的建筑，即可完成关卡。

## 操作

- 电脑：点击放置、拖动地图、滚轮缩放；`R` 旋转，`1 / 2 / 3` 选牌。
- 手机：点击选牌和放置、单指拖动地图、双指缩放。缩放按钮及居中按钮同样可用。
- 右上角可以开启合成音效、查看完整规则、开始新旅程。
- 刷新页面会恢复当前对局，包括尚未确认的放置步骤。清除浏览器站点数据会清除存档。

## 代码结构

```text
src/engine.js       板块、区域连通、旅人、结算与回合规则
src/art.js          本地 SVG 板块与图标
src/main.js         界面、触控、地图相机、本地存档和音效
src/style.css       响应式桌面与手机布局
tests/engine.test.js 核心规则和自动完整对局验证
```

没有远程图片、字体或游戏 API 依赖。音效使用 Web Audio API 即时合成。首次加载静态资源后，正在打开的页面可断网继续玩；目前没有实现离线缓存安装功能。
